Install

# from the release tarball — no npm account, no registry:
$ npm install -g https://github.com/garyleelty/agentledger/releases/download/v0.6.0/agentledger-cli-0.6.0.tgz

# or straight from the repository:
$ npm install -g git+https://github.com/garyleelty/agentledger.git
$ npx --package=git+https://github.com/garyleelty/agentledger.git agentledger

# or without npm at all:
$ curl -fsSL https://raw.githubusercontent.com/garyleelty/agentledger/main/install.sh | sh

Each release attaches its tarball using the repo's own token, so the first form installs whether or not agentledger-cli is on the registry (it is not yet — plain npx agentledger-cli still 404s). Node 22.5+.

Why it exists

If you pay per token, your invoice is a lagging indicator — you find out after the money is gone. agentledger answers the question while you are still working: what has this agent, this model, this week actually cost?

What it does

  • Reads local logs only — ~/.claude/projects, ~/.codex/sessions, ~/.local/share/opencode, ~/.local/share/kilo, ~/.dsh/sessions, ~/.openclaw/agents, ~/.pi/agent/sessions, ~/Library/Application Support/CherryStudio/Data, ~/.gemini/tmp, ~/Library/Application Support/CodeBuddy CN/logs, ~/Library/Application Support/Lingma/SharedClientCache/cache/db
  • Cache buckets priced separately — 2.00B of my 2.32B tokens are cache reads, billed at 10-25% of input
  • Never touches the network — no account, no key, no telemetry, ~5600 lines you can audit in one sitting
  • Fast — a full scan of 680M+ tokens takes about a second
  • Your rates, not mine — --prices my-prices.json overrides any model, partial entries merge over the built-in table; prices --template writes the file for you, naming exactly the models your ledger could not price
  • Honest about unknowns — a model with no built-in price is billed at a stated default and the report says so, with its dollar share, instead of quietly folding a placeholder into the total
  • Checked against the world, not itself — tools/crosscheck.mjs diffs token totals against ccusage on the same logs (it found four real bugs), and tools/audit_pricing.py diffs every price against the LiteLLM database weekly in CI
  • Billing blocks — agentledger blocks groups your usage into the windows a subscription quota resets in, with the active window's burn rate and projection. Every agent, not just Claude Code
  • Status bar — agentledger statusline in Claude Code's statusLine hook: live session cost, the active billing block, zero file reads on current payloads

Two JSON shapes, on purpose

json is the debugging shape: one row per record, with the session id in it. On Claude Code and Codex that id names a real log file under the agent's own directory, so a report built from it maps your projects and timestamps. aggregate is the shareable one — totals plus per-agent and per-model groupings, about 3 kB, and it is what the weekly digest is built from.

without cache $3853

concentration  top 10 of 315 sessions = 75.3% of all cache reads
priciest      $118  one Codex session in one repo
branch        $206  the web branch alone

Priced the same ledger with every cache-read token billed at its model's fresh-input rate and caching is worth $2,854 — the tool does not just report spend, it prices what prompt caching is worth. agentledger savings prints it. Concentration that high is not ordinary usage — it is context churn: a long session that keeps re-sending its prefix, or a tool returning large output every turn. agentledger waste points at which one.

Compared to ccusage

ccusage is the incumbent and it covers more agents, prefers Claude Code's own costUSD, but reports reasoning token counts only — it does not bill them in the OpenCode or Kilo lanes. If you want the most complete tool, use it.

Where agentledger is now level or ahead: Anthropic's 5-minute vs 1-hour cache-write TTLs are billed apart (x1.25 / x2) from the nested cache_creation block when logs carry it; every built-in price is reconciled against live LiteLLM in a weekly CI job, so a stale entry fails a build on a schedule instead of waiting on a manual refresh; savings prices the counterfactual — what this ledger would have cost with no prompt caching; and DSH (DeepSeek Harness) is a source it cannot read at all, which on this machine is 1.48B tokens, more than every other agent combined.

Two of its lanes report $0.00 for every model: OpenClaw's glm-4.7:cloud and stepfun/…:free are both missing from its embedded price table, so 31.39M tokens of real spend price to zero there. agentledger prices glm-4.7:cloud from six LiteLLM vendor rows that agree exactly on $0.60/$2.20.

The pitch that stays narrower and honest: ~5600 lines, zero dependencies, no network, no build step. You can read the whole thing before you trust it with logs that are effectively your entire coding history.

Support

agentledger is MIT-licensed and free forever. If it saved you a surprise bill, you can send something directly — no account, no signup, no intermediary:

ETH  0xB30a208B84814D3F7091Bb779f2b0225288349aE
BTC  1EKTrfpKc7fQwNYUv4oHLa2cna6NqDq3sM

Verify these before sending — the BTC address carries a base58 checksum and the ETH address an EIP-55 checksum, so a typo will not silently send funds somewhere else. You can also run python3 tools/tip.py from the repo to confirm the balance from public endpoints.

These are not just pasted in — python3 tools/prove_control.py re-derives both from the private key and signs with it, so you can confirm the addresses are really the project's before sending.

No ads, no paid tier, no license keys. Tipping is the only way this project makes money, and it is entirely optional.
